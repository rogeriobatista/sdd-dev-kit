# Exemplo — capacidade de negócio

## Intenção
Descreva em prosa o que o sistema deve fazer e o que fica de fora.
Use este arquivo como modelo; renomeie ou copie para um spec real em `specs/`.

## Cenários

### Cenário de domínio feliz @api
Dado um contexto inicial válido
Quando a ação principal ocorre
Então o resultado de negócio esperado é obtido

### Cenário de interface @ui
Dado que o usuário está na tela relevante
Quando interage com o controle principal
Então vê o feedback visual esperado
