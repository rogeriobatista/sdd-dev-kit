# `@rogeriobatista/core`

Portable SDD Protocol Kit core: `sdd.yaml` schema, phases, stack detection, ticketing (Linear/Jira), demo/evidence packs, and shell helpers.

```js
import { detectStack, fromTicket, buildDemo, parseSddYaml } from "@rogeriobatista/core";
```

Consumed by `@rogeriobatista/cli` and stack adapters. See the repository root README.
