# node-graphql-api

Tiny SDD example for **Node + TypeScript + GraphQL**.

```bash
npm run setup -w node-graphql-api
npm run smoke -w node-graphql-api          # vitest
npm run sdd:verify:all -w node-graphql-api # vitest + cucumber
```

`adapter: node-graphql` in `sdd.yaml`. Playwright not required.
