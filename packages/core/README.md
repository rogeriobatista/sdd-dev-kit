# `@sdd-dev-kit/core`

Portable SDD Protocol Kit core: `sdd.yaml` schema, phases, stack detection, ticketing (Linear/Jira), demo/evidence packs, and shell helpers.

```js
import { detectStack, fromTicket, buildDemo, parseSddYaml } from "@sdd-dev-kit/core";
```

Consumed by `@sdd-dev-kit/cli` and stack adapters. See the repository root README.
